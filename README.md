# 🐧 Linux Tools & Automation Scripts

A collection of useful Bash scripts for system management and monitoring across **macOS**, **Linux**, and **WSL** (Windows Subsystem for Linux).

## 📂 Project Structure

- **`/macOS`**: Scripts optimized for Darwin-based systems (e.g., memory management using `vm_stat`).
- **`/WSL`**: Tools tailored for Windows Subsystem for Linux environments.
- **`/General`**: Universal scripts that run on any standard Unix-like shell.
